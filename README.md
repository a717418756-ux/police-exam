# 短線雷達 StockRadar Pro — 使用導覽

> 版本 v72｜台股/美股短線波段量化決策 PWA｜繁體中文｜手機優化
> 核心理念：多維度交叉驗證 + 反散戶擁擠 + 每個結論可溯源到真實資料驗證

---

## 這是什麼

一個個人化的量化交易決策輔助工具，設計給短線波段（2-10日）操作使用。跟一般技術分析網站不同的地方：

- **每個結論都能往下追**——行為推理鏈把「指標→行為→走向」的過程完全攤開，不是黑箱燈號
- **方法論有文獻依據**——Wyckoff Method、VSA、行為金融學實證論文，皆標註來源
- **關鍵功能已用真實股票資料驗證**——不是理論上應該有效，是量測過確實有效才留下

---

## 核心使用流程（一次查詢會依序看到）

### 1️⃣ 決策分頁（最重要，優先看）
- **出手紀律門**：七道關卡（環境/週期/共振/公式/反明牌/軋空/大戶法人），任一紅燈=禁止進場；全綠附完整執行計畫（部位/停損/停利/VaR）
- **行為推理鏈**：把全系統彙整成「指標→行為→走向」三層，每個行為卡下方標註證據來源，衝突時明確警示（例如「主力偏多但整體走向偏空」）
- **行情溫度計**：判斷這段行情走到初期/中期/尾端——**這是解決「方向判對但追在訊號尾端」的關鍵功能**，用該股自己的歷史波段分布校準，非通用門檻
- **決策橫幅**：一句話結論，空方建議前會自動檢查反彈風險，避免無腦喊「做空」

### 2️⃣ 主力行為卡
- 主力意圖研判：分辨下跌是「洗盤」（洗散戶，將漲）還是「出貨」（真跌，續跌）——這是短線做空最關鍵的分岔
- **此股真實歷史驗證**：每次查詢自動用該股2年真實日K逐日重演，顯示這類判定在「這支股票」上過去準不準
- 融資融券、主力縱深（FinMind千張大戶/借券，選填）、反明牌雷達

### 3️⃣ 其他分頁
大盤環境、籌碼健康度、支撐壓力+定錨效應、共振確認、交易日誌

## 已用真實資料驗證的功能（誠實列出量測結果）

| 功能 | 驗證方式（最終：24檔×19年＋14年法人籌碼，含2008/2015/2020/2022熊市） | 最終結論 |
|---|---|---|
| 意圖判定（洗盤/出貨/進貨） | 7,908事件逐日重演，α=命中率扣除該股基準漂移 | **全域方向預測力≈0**（出貨為反指標，1,509事件僅47%真跌）；已改為「逐股α閘控」——判定在該股歷史α（貝氏收縮後）≥2才有行為鏈方向投票權 |
| 意圖判定×法人籌碼聯合 | 每事件按前5日外資/投信/自營自行方向分層（數千事件/格） | **證偽**：同向與反向命中率幾乎相同（洗盤52%/52%）；三法人共識3/3也僅54%。籌碼確認救不回全域方向預測；出貨+法人同賣反而更易反彈（46%）＝賣壓擁擠效應 |
| 意圖判定×趨勢環境（60MA） | 18檔2年初測有分化（α+7~8），24檔19年複測 | **未通過複測**：出貨×順勢縮至α-3、洗盤×多頭僅剩α+3.0（噪音邊緣）——事後選擇的教訓再添一例，不寫入系統 |
| 突破統計（False Breakout DB） | 19年3,934次突破事件 | **追突破期望值為負**：整體成功率僅38.4%（假突破率61.6%）；帶量40.9% vs 無量34.5%（量能確有鑑別力）；逐股28%~51%。系統顯示此股專屬成功率並在紀律門/橫幅勸阻追價 |
| FUSION極端值 | 116,759樣本分桶 | **兩端極值皆非方向訊號**：≥40後5日上漲率47.3%（α-2.5）、≤-40為51.6%（α+1.7）——極端=過熱/超跌溫度計；紀律門已對極端區除權 |
| 行情溫度計 | 960個判定點池化 + 重演2313/2885實際虧損單 | 尾端追單期望值較差；兩筆真實虧損進場都會被攔下（2313進空前夕讀「下跌·尾端79」） |
| 處分效應偵測 | 你自己的交易日誌 | 自動比對賺/虧單平均抱倉天數，量測「賺太快跑、虧太久抱」 |

```
第④層 決策出口   決策橫幅（結論+警示彙整+行動）｜出手紀律門（R1~R6紅黃綠燈+執行計畫）
                    ▲ 只在這兩處給「行動建議」，其他卡片一律只給「證據」
第③層 綜合推理   行為推理鏈（誰在做什麼→票數合成，共線折減+逐股α閘控）
                 七維共振（趨勢/動能/籌碼/結構/情緒/強弱/性格，Regime動態權重）
第②層 證據引擎   [方向類·已除權] 意圖判定(α≈0僅逐股復活)｜FUSION極端(溫度計非指針)
                 [時機類·有效] 行情溫度計(逐股波段百分位)｜日內型態(條件頻率)
                 [風控類·有效] 突破統計(38.4%基準)｜智慧停損(假跌破率)｜擁擠度
                 [價位類·工具] 支撐壓力｜圖形線位｜流動性池（可下單價位，非預測）
第①層 資料層     價量(Yahoo2年,還原+原始雙軌)｜籌碼(T86/融資/借券/千張/當沖/自營)
                 環境(大盤/期貨/PCR/VIX/類股廣度)｜統一快取CACHE_TTL+全鏈超時8s/20s
```

### 每個判斷的證據狀態（諾言：系統只說有證據的話）

| 判斷 | 證據等級 | 依據 |
|---|---|---|
| 方向預測（任何形式） | ❌ 已放棄 | 19年7,908事件+籌碼/環境分層全部α≈0 |
| 逐股α閘控投票 | ✅ 19年背書 | 逐股異質性真實存在（-13~+20），收縮防小樣本 |
| 順勢原則（逆環境=紅燈） | ✅ 結構性 | Regime逆風fail、順風pass、盤整警告 |
| 追突破勸阻 | ✅ 19年3,934次 | 成功率38.4%（期望值為負），帶量+6.4pp |
| 溫度計尾端防追單 | ✅ 逐股統計 | 960判定點+重演2筆真實虧損單皆被攔 |
| 反明牌/擁擠迴避 | ✅ 多源直測 | 當沖比重+融資+券資比+法人借券對照 |
| 賣壓擁擠反彈 | ✅ 副發現 | 出貨+法人同賣46%（連法人擠同邊都危險） |
| 停損擺放 | ✅ 逐股統計 | 結構位外+假跌破率動態緩衝+線位重疊偵測 |

### 資訊連接圖（無孤島原則：每個計算至少兩個消費者）

意圖判定→[α閘控]→行為鏈→橫幅｜溫度計→橫幅+紀律門+劇本｜突破統計→溫度計卡+橫幅+紀律門R6+線位｜
當沖→擁擠度+橫幅｜自營自行→行為鏈｜線位→停損重疊偵測+橫幅踩線警示｜Regime→共振權重+R1+橫幅｜
類股廣度→大盤卡假強偵測｜交易日誌→凱利勝率回填（唯一自動迴路，僅真實單≥5筆）

### 系統誠實性三原則（優化到此的終局形態）
1. **全域不說謊**：被證偽的方向宣稱全數除權，文字與19年數據逐字對齊
2. **逐股自我校準**：查任何股票當場用它自己的歷史算α/突破率/假跌破率/溫度計
3. **決策層只管風控與時機**：不預言方向，只回答「現在進場的期望值結構好不好」

---

**方法論教訓（本專案最有價值的產出）**：4檔看似有效（出貨67-80%）→18檔跌至54%→19年7,908事件證實≈0；籌碼聯合2檔試跑「同向80%」→24檔全量後52%/52%零分化；環境分層18檔α+8→19年歸零。**三次同型證偽**：小樣本假規律、事後選擇條件、單次分層的偶然分化——所有宣稱須經大樣本+基準線校正+熊市週期+跨股一致性四重考驗。逐股異質性為唯一倖存結論（3037出貨α+12、2498進貨α+19.7），由逐股α閘控捕捉。

**同樣重要——測過但沒有效、誠實撤回的**：Selling Climax、Ornstein-Uhlenbeck半衰期均值回歸模型，皆在真實資料/文獻查證後判定不採用，過程留有註解記錄。

## 設計原則

1. **多維度共振 > 單一指標**：七大獨立維度同向才是高勝率訊號，且共用底層證據的行為會自動折減權重，避免同一份證據投兩票
2. **不過擬合**：不因單次交易結果調參；新邏輯要在真實歷史資料A/B對照有明確改善才留下
3. **誠實揭露限制**：免費資料做不到的直接說做不到；勝率必附Wilson信賴區間；ETF窗口等概估資訊會標註「非成分股確認」
4. **反群眾而非追隨群眾**：AI普及讓散戶訊號趨同已有學術證據（Aghbabali et al. 2025），系統核心正是量化「這訊號有多少人看到」

## 部署方式

**前端**：全部檔案上傳 GitHub Pages 根目錄，不建子資料夾
**查詢後端**：Cloudflare Workers（worker.js），免費、全球節點快
**備份後端**：Google Apps Script（Code.gs），端點與查詢後端完全對等
**選填**：FinMind Token（免費註冊）啟用主力縱深卡

版本號寫在 `config.js` 的 `APP_VERSION`，每次更新會自動破快取，重新整理 PWA 即生效。
