# 短線雷達 StockRadar Pro

> 台股／美股日K分析 PWA｜繁體中文｜手機／Boox e-ink 優化
> 版本 v196（2026-10）｜原則：**只說有證據的話**——沒有回測證據的規則只提醒、不擋單；沒有資料就不顯示

---

## 一、系統架構

```
前端（GitHub Pages，純 JS PWA，15 支 js 平鋪根目錄）
   ├── 資料查詢 ──→ Cloudflare Worker（worker.js，主要）
   │                 └→ Yahoo Finance／證交所／櫃買中心／期交所／FinMind／新聞＋Gemini
   │                 └→ 情報面快照存 KV（綁定名稱 SYNC），資訊面校準用
   └── 雲端備份 ──→ Google Apps Script（Code.gs，備援＋備份）

本機：IndexedDB（交易日誌 stockRadarDB；資料暫存 stockRadarCache，上限 150 筆）
```

**雙後端對等**：worker.js 與 Code.gs 端點相同（benchmark／deepchip／fundamental／histuntil／intel／intelsnaps／margin／market／pool／range／scan），互為備援。Code.gs 只能用 ES5。

**資料暫存**：同一檔當日查過就用暫存，不重複抓。盤中 5 分鐘；收盤後到下次開盤（法人 16:00、FinMind 21:00 為界）；資料不完整 30 分鐘後重試；⟳ 按鈕強制重抓。

## 二、判斷流程（決策分頁由上而下）

```
① 出手紀律門   ──→ 只有兩級：🔴禁止（只用有回測證據的條件）／🟡未觸禁止＋提醒清單
                     附執行計畫：方向先看中期因子最強／最弱 20%，沒有才用勢能等級（標明未經回測），一律試單；橫幅標題的勢能與中期相反時以中期為準
② 決策橫幅     ──→ 🧭 分析方向（中期四因子＋短線紀律門）＋中期因子明細＋條件期望值＋警示
③ 行為推理鏈   ──→ 每個行為的證據攤開；少於 3 票不計分
④ 行情溫度計   ──→ 本段波段在此股歷史分布的位置（初期／中期／尾端）
⑤ 勢能（兵法） ──→ 趨勢 40%＋籌碼 30%＋量能 20%＋相對強弱 10%
⑥ 劇本         ──→ 多空兩套價位，停利用此股 5／10 日中位可達幅度
```

## 五、部署

**前端**：上表標「GitHub Pages」的檔案全部放 repo 根目錄 → Settings → Pages → main 分支根目錄。

**Cloudflare Worker**：Create Worker → 貼上 worker.js → Deploy。
- KV namespace 綁定名稱 `SYNC`（雲端同步、情報面快照）
- Secrets／變數：`GEMINI_KEY`（情報面 AI）、`GEMINI_MODEL`（選用）、`GAS_RELAY`（選用）

**GAS**：script.google.com → 貼上 Code.gs → 部署為網頁應用程式（執行身分＝我、存取＝所有人）→ 每次改完要「新增版本」重新部署。Gemini 金鑰放 Script Properties 的 `GEMINI_KEY`。

> 金鑰只放 Cloudflare Secrets／GAS Script Properties，**絕不寫進程式碼或貼到對話**；外洩就到 AI Studio 刪除重建。

**PWA 設定頁**：資料查詢網址（Worker）、雲端備份網址（GAS）、FinMind Token（選填，主力縱深用）。
